# v0.4.0-alpha.8 - A Persona You Can Open, Edit and See

**Date:** 2026-11-08

## Highlights

- **Open a persona from its name.** The persona's name above its words is a link: it opens the
  persona, and its name, description, routing keywords and prompt can be changed and saved to
  Mirror (CR217, Core CR205).
- **A persona's own image.** On the same screen a persona can take an image, which then stands in
  every one of its bubbles where the ◇ stood. The image stays on this Mac (CR218).
- **A deletion you can read.** The Delete Journey list uses the theme's ink, legible on the light
  themes, and the dialog's title is the Journey that will be deleted (CR205).
- **Still Intel only, and not signed.**

## Where We Started

Alpha.7 gave each persona its own name in the dialogue, but changing a persona still meant leaving
the app for Mirror's command line, and every persona spoke behind the same diamond, told apart only
by a colour. Deleting a Journey on Daylight, Mist or Parchment showed its list in a grey chosen for
the dark theme, nearly invisible on white, under a title that did not say which Journey would go.

## What Changed

- **The core.** The pin moves from `mirror-mind@0.41.0` to `0.42.0`, the tarball npm serves, checked
  by both hashes. It adds the calls that list, read and update a persona, shaped like the Journey
  calls: a write names the version it read and is refused if the persona changed since, and a
  refused value comes back as a sentence naming the field (CR217, Core CR205).
- **The persona screen.** Opened from a persona's name. Saving changes only what changed; a saved
  name is the one the bubbles show at once. A changed prompt reaches an open conversation only after
  its next compaction, and the screen says so (CR217).
- **The persona image.** A PNG, JPEG or WebP of at most 5 MiB, made a 512 px PNG and kept by
  Nautilus for the home, by the persona's id. Choosing or removing one applies at once, without
  waiting for Save. Nothing of it reaches Mirror (CR218).
- **The deletion dialog.** The list and the warnings about the folder's files take the theme's text
  colour; the Journey's name is the title, under "Delete Journey", and a long name wraps (CR205).
- **Two commands under the guard.** Reading a persona and loading the persona names ran off the main
  thread without the lock every such command takes first. Both take it now (found while building
  CR218).

## What Does Not Change

The same Pi as v0.4.0-alpha.7. Nothing in a home's database changes shape: the core's version needs
no migration, and a persona edited here keeps its version, model and inheritance as they were. Your
stored preferences are kept.

## Conscious Exclusions

- **A changed prompt waits for compaction** in an open conversation. The core's fix (Core CR206) is
  captured, not built.
- **Personas cannot be created or deleted here** yet, only edited.
- **No way yet to set a Journey's default persona.**
- **Persona colours can collide**, as in alpha.7; an image is the way around it for now.
- **No signing, notarization or Apple Silicon build** yet.

## What We Learned

Data belongs to Mirror and appearance to the app: the persona's words live in the core, where any
client reads them, and its image lives with Nautilus, as a Journey's does. And a census of commands
is only as good as the list of files it reads: two new files were outside it, and with them two
commands without the guard.

## Next Horizon

The core's redelivery of a changed prompt (Core CR206), a way to set a Journey's default persona,
and the older open work (RS027).
