# v0.4.0-alpha.21 - Nautilus on macOS 12, and a pasted line that no longer freezes

**Date:** 2026-11-22

## Highlights

- **The app opens on macOS 12.** alpha.20 showed a black window there, because one regular
  expression used a construct that WebKit cannot read and the whole page was refused. The bundle is
  now built for the WebKit of macOS 12.0, and a test refuses what that engine lacks (CR265).
- **A pasted message no longer freezes the window.** Text pasted from a phone can end its lines with
  an invisible U+2028. In a list item it made the message reader loop until memory ran out, and the
  Journey would not open again. It reads now, and a line the reader cannot place is shown as text
  instead of stopping it (CR267).
- **That message reaches Mirror.** The Mirror host split a request at the same character, so the turn
  was complete on screen and never delivered, and Settings offered a repair that could not finish.
  The host and the sign-in helper read a line on newline alone (CR268).
- **A Journey with old, contradictory turns opens.** Four turns out of 269 that cited another turn's
  Pi entries made a migrated Journey refuse to open. Such a settled turn is now read as unknown, and
  a Journey that cannot be read names the cause (CR266).
- **OpenAI's sign-in page says "Nautilus for Mirror",** not "Mirror Desktop" (CR264).
- **Still Intel-only and unsigned on macOS;** the Windows bundle is unsigned.

## Where We Started

A person's Mirror moved from a Big Sur MacBook Air to a spare one on macOS 12.7.6. The released app
opened black there. With that fixed, the Journey she uses most would not open: after she pasted a
long note from her phone, the old app froze, was force-quit, and from then on the Journey loaded
for ever on the old app and on Nautilus alike. Underneath were two defects and a third left by the
old app: the invisible separator in her text, met twice, and four turns of history that each named
another turn's Pi entries.

## What Changed

- **macOS 12 (CR265).** The lookbehind added by CR253 became a capture that puts the mark back, with
  the same result. Vite 7 builds for Safari 16 by default while the declared floor is macOS 12.0,
  whose WebKit is 15.0; the build now targets `safari15`. Seven `.at()` calls and one
  `Object.hasOwn`, which that engine lacks and which fail where they run, became index reads and
  `hasOwnProperty`. A test refuses a lookbehind, those built-ins and later ones, and another target.
- **Message reader (CR267).** The list, numbered-list, quote and heading patterns let `.` cross
  U+2028. A pass that leaves the reader where it found it reads the line as text and drops the
  empty list it left.
- **Mirror host (CR268).** The host and the sign-in helper read their input by bytes, ending a line
  only at `\n`; Node's `readline` also ended one at U+2028 and U+2029, which JSON keeps raw inside a
  string.
- **Old turns (CR266).** When a settled turn cites a Pi entry an earlier turn owns, the earlier
  turn keeps it and the later one is read as unknown, whole; the Journey's transcript is the one a
  hand repair of the same file produced. The latest turn, the only one this run can have written,
  still refuses. "This Journey conversation could not be loaded" now adds the cause, for example
  `runtime_read_failed (pi_surface_metadata_conflict)`.
- **Sign-in name (CR264).** The name Pi gives OpenAI is "Nautilus for Mirror", in Sign in with
  ChatGPT and in the Codex login. Anthropic's login does not take a name.

## What Does Not Change

The same Pi, the same Node, the same Core (`mirror-mind@0.44.2`) and the same Conversations as
alpha.20. No schema change and no migration: the home stays at `018_drop_hook_injected`. A message
is stored as it was sent; the invisible separators are not removed from it.

## Conscious Exclusions

- **The look on Safari 15 is not complete.** The stylesheet still uses `color-mix()`, one container
  query and two `:has()` selectors, which that engine drops: some borders, accents and backgrounds
  are missing on macOS 12 unless Safari was updated to 16.2 or later. Nothing stops working.
- **No cleaning of pasted text** in the composer; whether to normalise U+2028 on paste is a separate
  decision.
- **The first delivery attempt of some old turns** still meets an idempotency conflict and is healed
  by the compatibility retry, as in alpha.20.
- **No signing or notarization,** on macOS or Windows, and **no Apple Silicon build.**

## What We Learned

The gates proved what they were built to prove and nothing about the machine the app would meet.
Every test passed while the bundle could not be parsed on the oldest Mac the app says it supports,
and twice an invisible character was read by a tool that has its own idea of where a line ends.
The fixes are small; what they add is a gate that knows the floor and a reader that never stands
still.

## Next Horizon

Whether the stylesheet gets fallbacks for Safari 15 or the record states that its look is complete
only from Safari 16.2 waits for the Navigator. The diagnostics surface can show the turns read as
unknown, and the idempotency conflict on first delivery is its own CR.
