# v0.4.0-alpha.27 - The Invocation mode in Advanced, and a steadier look on macOS 12

**Date:** 2026-11-26

## Highlights

- **The Invocation mode, in Settings › Advanced.** The choice between Mirror runtime Pi and Raw local Pi
  left Models, where it sat beside the model and the thinking level, and is saved as soon as you choose
  it, applying from the next message. While Raw local Pi is chosen a note says what it is (CR292).
- **A steadier look on macOS 12.** Two narrow-column rules that an older WebKit dropped, the words of the
  Tree tools and the time on a Compact line, now give the narrow form there, and two `:has()` selectors
  became classes. A new check refuses either construct without that answer (CR293, CR294).
- **The first release a Windows install can be offered as an update.** The Windows installer of alpha.26
  was published on 2026-11-26; this release is the one its update will be tested with, after its own
  Windows publication is run.
- **Still Intel-only and unsigned on macOS;** the Windows bundle is unsigned.

## Where We Started

Alpha.26 left the Invocation mode among the model and the thinking level, which people change daily,
though it decides which prompt Pi receives and whether its RPC mode runs. It also left, in the list of
what CR281 had not done, two container queries and two `:has()` rules: an engine that does not know one
drops its rule without a sound, so macOS 12.0, whose WebKit is 15.0 until Safari is updated, drew those
places differently and nothing refused it. And the Windows installer, built and signed by the new route,
had not yet been published.

## What Changed

- **The Invocation mode (CR292).** The field left Models and is in Advanced, under the prompt cache
  option, with the same two labels. Choosing replaces that one field of the settings and nothing else;
  if the save fails the select returns to the stored mode and the error shows under it. Save global
  defaults now saves the model and the thinking level only and keeps the stored mode, and Restore
  Nautilus defaults still returns it to Mirror runtime Pi. A note under the select says what Raw local Pi
  hands Pi: a task packet and a request for a JSON mission draft, without Pi's RPC mode.
- **Container queries (CR293).** Each of the two is repeated under `@supports not (container-type:
  inline-size)`, so an engine without them uses the narrow form at every width, the one that always
  fits. A current engine is as before. A stylesheet check, beside the one for scripts, fails on a
  container rule without that copy.
- **`:has()` (CR294).** The Journey menu that holds a reason and the compaction notice that holds a
  Dismiss button carry a class for it, which every engine reads. The same check fails on any `:has(`.

## What Does Not Change

The same Pi, the same Node, the same Core (`mirror-mind@0.44.2`), the same Claude Code install and the
same Conversations as alpha.26. Nothing outside the frontend changed: no Rust, no new native command, no
schema change and no migration, the home staying at `018_drop_hook_injected`. The stored settings have
the same shape.

## Conscious Exclusions

- **The macOS 12 fallbacks were not seen on a WebKit older than a current Mac's.** They rest on the text of
  the stylesheet, the built stylesheet and the rule that an engine drops what it does not know. The price
  of the form that always fits is that the words and the time are gone at every width in those two
  places there, not only at the narrow ones.
- **Five colour variables of the light themes** still hold a `color-mix()` that a sibling declaration
  cannot repair; on macOS 12 the text that reads them takes the inherited colour.
- **Raw local Pi is still offered.** Whether it should be is a question this release leaves open.
- **Two contributions under review** are not part of it: a checkbox label in the light themes, and links
  inside bold text.
- **The Windows update has not been seen.** It is tested with this release, after its Windows
  publication, and not before.
- **No signing or notarization,** on macOS or Windows, and **no Apple Silicon build.**

## What We Learned

A window opened from an old bundled Dev app, built before the Advanced tab existed, looked like a tab
that had vanished. A validation has to say which build it looked at. And a list of small items written
from a summary named one that earlier records had already done; the records are read before a change
is captured.

## Next Horizon

The first Windows update, from alpha.26 to this release, which closes CR287. Then the Windows pages of
the site. And, when Apple answers, signed and notarized distribution.
