# v0.4.0-alpha.7 - A Persona by Its Subject, Under Its Own Name

**Date:** 2026-11-08

## Highlights

- **The persona follows the subject, or there is none.** The embedded Mirror core is now
  `mirror-mind@0.41.0`. A turn's persona is chosen by what you asked, not inherited from the
  previous turn; a turn no persona fits is answered by the agent, π, unsigned (CR216, Core CR203).
- **The persona's own name.** The bubble says "Analista SQL", the name the persona keeps, where it
  said "Analista Sql", its id made readable. The name stays when the conversation is opened again
  (CR216, Core CR204).
- **Tables with an empty first header cell.** A comparison table whose first column names the rows
  is drawn as a table, not as a paragraph of pipes (CR215).
- **Still Intel only, and not signed.**

## Where We Started

Alpha.6 drew each answer beside its persona, but the core it embedded chose that persona by counting
keywords, and when none scored the previous turn's persona kept answering: specialists from
unrelated fields answered on a book's Journey. The bubble had only the persona's id to name it by.
And a table that left its first header cell blank, as comparison tables do, was read as text.

## What Changed

- **The core.** The pin moves from the preview `0.40.0-next.1` to the release `0.41.0`, the tarball
  npm serves, checked by both hashes. The core asks a decision model which persona the subject
  belongs to, and takes its answer only when it is confident; otherwise the Journey's default
  persona, otherwise none. Measured on 100 of the Navigator's own turns: 93 right, 3 wrong, 4 missed.
  The core version also carries 0.40.0 and 0.40.1 (CR216).
- **Names.** The core hands the persona's name beside its id. Nautilus keeps the names it was handed
  for the home, by id, in an owner-only file, because Pi's record of a turn keeps only the id; a
  persona without a name keeps its readable id (CR216).
- **Tables.** A table written one row per line may leave header cells empty, as GitHub reads it; a
  header with every cell empty is still not a table, and a table written on one line still refuses
  empty cells, because there `| |` separates the rows (CR215).

## What Does Not Change

The same Pi as v0.4.0-alpha.6. Nothing in a home's database changes: the core's version needs no
migration. Your stored preferences are kept.

## Conscious Exclusions

- **No way yet to set a Journey's default persona.** The core reads it; setting it is a core
  follow-up.
- **The core's wording for a turn with no persona** is a first draft.
- **Persona colours can collide**, as in alpha.6.
- **The deletion dialog's pale list and title (CR205)** wait for a later version.
- **No signing, notarization or Apple Silicon build** yet.

## What We Learned

Installing the core on the machine did not reach the app: Nautilus runs the core it pins, so a core
release reaches it only through a Nautilus release. And a name the core hands only at delivery time
is lost on reopening unless the app keeps it.

## Next Horizon

A way to set a Journey's default persona, CR205, and the older open work (RS027).
