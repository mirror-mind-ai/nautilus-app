# v0.4.0-alpha.20 - The whole briefing, and a way back into Claude

**Date:** 2026-11-21

## Highlights

- **The Journey Briefing shows everything.** The panel renders the Journey's whole content as
  markdown: each section, the lists, the paragraph breaks. It is the same text the agent receives
  on every turn, read from Mirror each time, and Reload shows an edit made with
  `mirror identity set` without restarting the app (CR263).
- **Sign in to Claude again from the app.** Settings > Model providers asks Claude Code whether it
  is signed in and says "Connected · signed in to Claude" or "Signed out of Claude", with a
  **Sign in** button that finishes in the browser. A turn that fails because Claude is signed out
  says "Claude is signed out, so this turn could not run." with a **Sign in to Claude** button
  (CR262).
- **The drop sentence goes away.** "Moved X into Y" leaves after 6 seconds, a refusal after 12, and
  both are readable in daylight, mist and parchment (CR261).
- **The Core moves to `mirror-mind@0.44.2`,** which adds the read behind the briefing (Core CR217).
- **Still Intel-only and unsigned on macOS;** the Windows bundle is unsigned.

## Where We Started

Three small frictions found in daily use, none a bug in the sense of a wrong result. The briefing
panel showed one flattened line, the Journey's description, while the agent was given the whole
text, so the panel could not be used to check what the agent knows. When the Claude sign-in
expired, Settings kept saying Connected, the turn failed with the provider's own words, and the way
back was to find the app's Claude Code inside Application Support and run a command in a terminal.
And the sentence that confirms a Journey move stayed on screen until the next gesture, and was
hard to read on the light themes.

## What Changed

- **Briefing (CR263).** The Core's `readJourney` answers one Journey's content uncut. The panel
  leaves out only the title and the Status and Stage lines that come before the first section,
  because the app shows those elsewhere; the same lines inside a section stay. The Description
  heading stays, also for a Journey that has only a Description. A failed read says so and why, and
  never falls back to the short description. The sidebar, the search and the canvas still use the
  description.
- **Claude sign-in (CR262).** The app asks its own Claude Code for the sign-in status and runs its
  `auth login` for you, showing the page to visit and a field for a pasted code in the panel Pi's
  sign-in already uses. Only one sign-in, Pi's or Claude's, runs at a time. The sign-in is the one
  your own Claude Code on this computer uses, so signing in here signs it in too.
- **Drop sentence (CR261).** The lifetime depends on what the sentence says: a confirmed move 6
  seconds, a refusal 12, "Moving" until Mirror answers. The light themes take their own readable
  inks, measured against the sidebar's background.
- **The pin.** `mirror-host/pin.json` names `mirror-mind` 0.44.2, release `v0.44.2`, commit
  `4ceb76d9`, with the tarball npm serves checked by its sha256 and sha512.

## What Does Not Change

The same Pi, the same Node and the same Conversations as alpha.19. No schema change and no
migration: the home stays at `018_drop_hook_injected`.

## Conscious Exclusions

- **No sign-out button,** and no separate Claude sign-in for the app: it shares the one on this
  computer. Console sign-in is not offered.
- **The setup screen is unchanged:** an installed Claude Code still counts as a connection there.
- **The briefing is read only.** Editing it from the panel is not part of this alpha.
- **Other sidebar notices** keep their lifetimes; only the drop sentence changed.
- **No signing or notarization,** on macOS or Windows, and **no Apple Silicon build.**

## What We Learned

Looking at what the agent receives is a different act from looking at what the app summarises of
it. The registry's description was made for a sidebar and was good at that, and every surface that
borrowed it for another job showed less than the job needed. The smallest honest fix was one more
read in the Core for the one place that needs the whole, not a heavier tree for all of them.

## Next Horizon

Back and forward shortcuts and clickable path segments in the Agentic Field wait for the Navigator
to ask for them. The settlement timings still decide whether the half of CR157 left out is
recaptured, and CV-011, an embedded Pi, waits for an Explorer pass.
