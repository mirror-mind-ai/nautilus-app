# v0.4.0-alpha.15 - Say when to use an intent, and a key for the sidebar

**Date:** 2026-11-13

## Highlights

- **An intent says when to use it.** A Model Intent may carry one line of up to 160 characters,
  in your own words, shown under its name in the model menu and in Settings, and edited in the
  intent form ("When to use"). A short name cannot say when to choose it; the line can (CR257).
- **The menu wraps the line instead of widening.** The model menu stops at 420px, so a long line
  breaks onto a second line and the menu keeps its shape (CR257).
- **A key toggles the Journey sidebar.** Command+B on macOS, Ctrl+B elsewhere, expands or collapses
  the sidebar, the same move the ‹ / › button runs. It works while typing in the Composer, which
  is plain text with no bold (CR258).
- **The button names the key.** Its tooltip reads "Collapse Journey sidebar (⌘B)" on macOS and
  "(Ctrl+B)" elsewhere, and `aria-keyshortcuts` declares the same key to assistive technology (CR258).
- **Still Intel-only and unsigned on macOS;** the Windows bundle is unsigned.

## Where We Started

After alpha.14 an intent was a purpose with a model per provider, but its name was all the menu
showed. A name short enough for the footer cannot say when to choose it, so the choice fell back on
remembering the model behind it, the very thing an intent exists to spare. Separately, the Journey
sidebar could only be expanded or collapsed with the mouse, and the window had no keyboard shortcut
at all.

## What Changed

- **The store.** The Model Intents file says schema 2.1.0 only while some intent carries a line, and
  stays 2.0.0 otherwise, so a store without lines is unchanged. The line is refused in 2.0.0, so each
  schema keeps its exact shape; it is trimmed, bounded, and free of control characters, and a blank
  line is dropped. The native validator follows the TypeScript one.
- **The shortcut.** A pure predicate decides the match: the primary modifier for the platform, the b
  key, and no second modifier. Ctrl+B on macOS moves the text cursor, so it is left alone there. One
  window listener reads the latest toggle through a ref and never re-subscribes.

## What Does Not Change

The same Pi and the same `mirror-mind@0.44.0` core as alpha.14. No table in a home's database
changes, and the agent settings file is untouched. An intents file with no lines is still 2.0.0.

## Conscious Exclusions

- **An older app cannot read a 2.1.0 file.** Once an intent carries a line the file says 2.1.0, which
  alpha.14 refuses; clear the lines, or put the earlier file back, before going back a version.
- **No native menu item carries the accelerator,** so the shortcut is not in the menu bar; the tooltip
  and `aria-keyshortcuts` name it.
- **The shortcut has not been seen on a Windows machine,** only proven in tests with the platform
  simulated.
- **No signing or notarization,** on macOS or Windows, and **no Apple Silicon build.**

## What We Learned

A name is a handle, not an explanation: the sentence that says when to reach for something belongs
beside it, in the owner's words. And a shortcut is two decisions, the key and the way to find out
about the key; shipping the first without the second leaves it unused.

## Next Horizon

voice component from the published artifacts on a Windows machine, signing and notarization, and a
