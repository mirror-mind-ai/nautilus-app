# v0.4.0-alpha.18 - An Agentic Field that works like a file manager

**Date:** 2026-11-16

## Highlights

- **The Context map is gone; the Agentic Field replaces it.** The tab is named Agentic Field (also in
  Settings > Extensions, where it stays off until switched on). It shows the Journey's briefing and
  the files in its workspace, and nothing else (CR156).
- **One compact surface.** The tree and the viewer are drawn as a single framed surface, with a
  toolbar on top and a path bar at the foot, the way a file manager frames its content (CR260).
- **Back, forward and reload.** The toolbar walks the places you have been, files included. Reload
  reads both panels again: the tree and what the viewer shows (CR260).
- **A divider you can drag.** Move the line between the tree and the viewer with the mouse or the
  arrow keys, double click to reset, and drag it to the left edge to fold the tree away. The split is
  remembered for you, the same in every Journey. Expand preview stays (CR260).
- **A path bar that opens what it names.** The foot shows the full path of the selection and opens
  the folder or the file when clicked (CR260).
- **Folders open to their contents,** with an Open folder action, and the workspace root can be
  selected and has its own context menu (CR156, CR260).
- **Still Intel-only and unsigned on macOS;** the Windows bundle is unsigned.

## Where We Started

The Agent Field was the Context map: a page of territories and presence markers showing what the
agent could see, with an admitted-context panel beside the files. It said again, in several places,
what the screen already showed, and its two cards sat apart with a gap between them. The Navigator
asked first to simplify it, then to bring it closer to Finder or Windows Explorer.

## What Changed

- **Simplified in six steps (CR156).** The header, the admitted-context section and the presence
  markers went first. The Journey Briefing returned as the ground of the field, the workspace root
  became selectable, and a folder opens to a listing of its contents. The admission and context-map
  code was then deleted, not hidden.
- **A file manager's frame (CR260).** One surface with a tinted sidebar and a hairline, a toolbar
  (back, forward, reload, the Journey Briefing as an icon, the place's name, Open folder or Open
  file, Expand preview), the draggable divider and the path bar.
- **The Journey Briefing is a button.** It sits beside reload, stays pressed while shown, and the
  preview titles it "Journey Briefing".
- **Right click on the root.** The tree's root opens the same Reveal Folder menu as its folders.
  This one needs the native side: revealing the workspace root now works.

## What Does Not Change

The same Pi and the same `mirror-mind@0.44.0` core as alpha.17. The Agentic Field is still an
extension, off by default. Nothing in the Journey's files or in what the agent is given changes: the
tab only shows them differently.

## Conscious Exclusions

- **No keyboard shortcut for back and forward yet.**
- **The path bar is one link,** not clickable segments.
- **The toolbar's Open buttons and the path bar open the same thing,** as a file manager's do; one
  of them can go if it reads as redundant.
- **No signing or notarization,** on macOS or Windows, and **no Apple Silicon build.**

## What We Learned

Moving a surface toward a familiar tool is a series of small questions the tool has already
answered: where the path goes, what a divider does at the edge, what a root offers on a right click.
Taking each step to the Navigator's eyes in dev found what no test could, such as a reload that
should read both panels and a briefing named twice.
