# Releases

Narrative release notes for Mirror Desktop live here. They follow the Mirror Core release-note shape: digest, highlights, narrative context, changed behavior, conscious exclusions, lessons, and next horizon.

Release notes are local preparation artifacts. Creating or editing them does not authorize a Git tag, push, notarization, public release, production updater manifest, or runtime installation.

- [v0.2.0-alpha.58 — Your Mirror, Found](v0.2.0-alpha.58.md) — If you already use Mirror, Mirror Desktop now finds it for you. Instead of a form asking for three

- [v0.2.0-alpha.57 — A Save That Cannot Hold the Application Hostage](v0.2.0-alpha.57.md) — When Mirror does not answer while a turn is being saved, the application now stops waiting after
30 seconds instead of forever. Last week one save waited eleven minutes, and while it did every other
action queued behind it. A timed-out save is kept on this machine and tried again, and the reason
Mirror gave is now recorded instead of discarded.
- [v0.2.0-alpha.56 — A Refusal That Says Why, Without a Restart](v0.2.0-alpha.56.md) — When the model provider refuses a turn, the application now names the reason on the spot. The reason
was always on disk and the code to read it shipped ten days ago, but it only ran when a Conversation
was reopened — and a refused turn never reaches that path on its own. Three refusals in a row went
unexplained in the field before this was found.
- [v0.2.0-alpha.55 — A Repair That Leaves a Trace, and a Write That Cannot Drop Another](v0.2.0-alpha.55.md) — A settlement rescued by recovery used to leave no record of the rescue, so reading the ledger a turn
repaired seconds later was indistinguishable from one never repaired at all — a gap that blocked
diagnosis six times. Every recovery route now writes a record naming itself, in the same ledger and
the same shape as an ordinary settlement. Separately, an agent-settings write can no longer be
dropped by another: no caller supplies a baseline any more, so none can supply a stale one.
- [v0.2.0-alpha.54 — Columns That Wrap, and a Canvas That Uses Its Width](v0.2.0-alpha.54.md) — A table cell that could neither wrap nor grow past its cap also could not shrink, so it rendered
outside its own box and painted over the column beside it. On the Canvas the progress bars were
covered by the text of the cell to their left, and both markdown table renderers carried the same
pair of declarations. Cells now wrap, code spans stay whole, and the Canvas is no longer held to a
prose reading measure it never needed, so its tables use the panel's whole width.
- [v0.2.0-alpha.53 — One Finishing, and Every Exit Reads It](v0.2.0-alpha.53.md) — Finishing reached the screen through two paths, and every exit the application offered was attached to only one of them. A turn that froze on the other path showed Finishing with no sentence, no button and no recovery, and the two notices built for exactly that moment were both silent. The application now derives Finishing once, from what the composer actually draws, and every exit reads the same value.
- [v0.2.0-alpha.52 — Recovering an Answer That Was Already Saved](v0.2.0-alpha.52.md) — When a turn hangs after the agent has already answered, the application now notices and brings the answer back. Underneath, the recovery that was supposed to repair these turns had been refusing every one of them for two weeks — on arithmetic that could never succeed — and it now attributes a stranded turn to its own request.
- [v0.2.0-alpha.51 — A Model Per Conversation, and an App That Says Why It Stopped](v0.2.0-alpha.51.md) — A model you choose inside a conversation now stays in that conversation, instead of silently becoming the default for the whole Journey.
