# v0.4.0-alpha.13 - Files alone, copy buttons whole, Windows proven

**Date:** 2026-11-12

## Highlights

- **A message of files alone is a message.** It can be sent with the text field empty (CR250), shows
  its bubble and files live and after a reload (CR252), and reaches the Core with the names of the
  files, so the turn is routed to a persona like any other instead of running with no Mirror
  context (CR253).
- **No imitated signature in the text.** A reply that copied the persona signature onto the end of
  its own line has it taken off, and it names no speaker: only the delivered context does (CR253).
- **The copy buttons are whole again.** The quoted draft's "Copy text" pill had been squeezed into a
  small circle with its label spilling out, and a code block's copy button was hidden until hover.
  Both keep their own shape (CR254, seen in alpha.12).
- **Voice on Windows with accented user names.** The Windows voice component runs with relative
  ASCII paths, so a profile such as "João Çãõ Silva" no longer breaks it (CR244).
- **Windows is installed and launched in CI,** not only built: the installer is run silently, the
  registered version, the executable, the bundled Node and the shortcut are checked, the app is
  launched and then uninstalled (CR248). A macOS CI runs the same suites and the tests that need a
  real host (CR243). Both workflows pin their actions by commit and carry a read-only token (CR251).
- **Still Intel-only and unsigned on macOS;** the Windows bundle is unsigned.

## Where We Started

Alpha.12 brought Nautilus to Windows, but it had been installed from a published artifact on no
Windows machine, and the first two clean installs found that the voice component failed for a user
name with accents. On any platform, sending only files left no visible bubble, and the turn ran with
no persona because the Core refuses an empty prompt. A change to the bubble's own copy button had also
reached the copy buttons inside it.

## What Changed

- **Windows, from a contributor's clean machines.** Rodrigo Immaginario installed the app on two
  clean Windows 11 machines and sent seven pull requests, all merged with their authorship: the voice
  component with relative paths (CR244, #20), `~` model aliases managed by Pi (CR245, #18), a
  platform-neutral project path hint (CR246, #19), bundling only the NSIS installer (CR247, #14),
  the install check in CI (CR248, #15), a development app with its own executable name (CR249, #16)
  and the message of attachments alone (CR250, #17).
- **CI.** A macOS workflow (CR243) and the Windows workflow now share their contract and differ
  only where the platform forces it; both pin every action by commit and use a read-only token
  (CR251).
- **Files alone.** The bubble draws when the message has text or files, and a reload keeps an empty
  user entry whose message carries files (CR252). The Core's doorman is given what was typed or,
  when nothing was, the display names of the files and never their folders; an imitated trailing
  signature is taken off after a sentence ends, while a diamond the sentence itself uses stays; the
  bubble of files alone opens with its files (CR253).
- **Copy buttons.** The three rules of the bubble's own copy button now apply only to the button
  that is the bubble's direct child (CR254).

## What Does Not Change

The same Pi and the same `mirror-mind@0.44.0` core as alpha.12. No table in a home's database
changes. The voice manifest, the Windows voice binary and both models are untouched.

## Conscious Exclusions

- **No signing or notarization,** on macOS or Windows.
- **No Apple Silicon build;** macOS remains Intel-only. The macOS CI runs on arm64 and does not
  exercise the shipped x64 binary or build the disk image.
- **The `~` model alias (CR245) was merged but not exercised,** since Pi listed no such model at the
  development check.
- **Which persona a file name routes to is the Core's to decide;** a name that says little may route
  to none, and the reply then carries no signature.
- **Not yet installed from the published artifact on Windows,** though the installer is exercised
  in CI and was shown on two clean machines.

## What We Learned

A rule written for one thing can reach its neighbours: a selector for the bubble's own button
matched every button inside it, and only a published build, read by someone who quoted a draft,
showed it. A turn with nothing typed is still a turn: the Core refused it for being empty, and the
silence that followed looked like a persona leaking into the text. And a path that is fine in ASCII
can fail on a person's own name, which only a machine that is not ours reveals.

## Next Horizon

Installing the Windows app and its voice component from the published artifacts on a Windows
machine, running the real-host tests on Windows CI, signing and notarization, and a conversation
held with a persona (CV-015's next design step).
