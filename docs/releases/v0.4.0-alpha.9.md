# v0.4.0-alpha.9 - A Persona Edit That Takes Effect at Once

**Date:** 2026-11-08

## Highlights

- **An edited prompt reaches the open Conversation.** The embedded Mirror core is now
  `mirror-mind@0.43.0`. The next turn a persona answers after its prompt changed carries the new
  text, marked as replacing the earlier one (CR219, Core CR206).
- **Only the prompt counts.** Renaming a persona or changing its description sends nothing new
  to the model.
- **Still Intel only, and not signed.**

## Where We Started

Alpha.8 let you edit a persona's prompt from its name, but the core it embedded gave a
Conversation a persona's prompt only once. In a Conversation where that persona had already
spoken, the edit waited for the next compaction, and the persona screen said so under the prompt.

## What Changed

- **The core.** The pin moves from `mirror-mind@0.42.0` to `0.43.0`, the tarball npm serves,
  checked by both hashes. The core remembers, per persona it delivered to a Conversation, a short
  fingerprint of the prompt; when the prompt changes, the next turn routed to that persona delivers
  it again under a header saying it replaces the earlier one. A compaction starts over, as before
  (CR219, Core CR206).
- **The note under the prompt** now says a changed prompt reaches each Conversation the next time
  the persona speaks there, open ones included (CR219).

## What Does Not Change

The same Pi as v0.4.0-alpha.8. Nothing in a home's database changes shape: the core's version
needs no migration. A Conversation open before this version keeps the personas it already holds
and picks up only edits made from now on. Your stored preferences are kept.

## Conscious Exclusions

- **The earlier text stays in the Conversation** until a compaction; the new section says which
  one is in force.
- **Personas cannot be created or deleted here** yet, only edited.
- **No way yet to set a Journey's default persona.**
- **No signing, notarization or Apple Silicon build** yet.

## What We Learned

An edit is only as real as the place it reaches. The screen could change the prompt in Mirror,
but the Conversation the Navigator was looking at kept answering from the old one; the fix
belonged to the core, which decides what enters the context, not to a warning in the app.

## Next Horizon

A way to set a Journey's default persona, and the older open work (RS027).
